STRIMKO TEST DONATE

Это отдельная урезанная версия панели донатов для ручного тестирования.

Что оставлено:
- Ручной тестовый донат: ник, сумма, сообщение.
- Кнопка «Проверка системы».
- Эффект effects/money_rain.webm.
- Отдельный звук эффекта effects/money_rain_audio.ogg.
- Случайные звуки из папки sounds.
- TTS: ник, сумма, сообщение.
- Выбор режима TTS и отдельные громкости TTS/обычных звуков/эффекта.
- Тот же Firebase donateManager/events и donateManager/settings.

Что убрано из панели:
- «Случайный донат».
- Раздел «СОХРАНЕНИЕ».
- Автоматические донаты.
- Статистика, база ников/сообщений и прочие панели полного менеджера.

OBS-ссылка для теста:
https://maxbaxlolka.github.io/STRIMKO_DONATE_MANAGER/index.html

В OBS: Источник → Браузер → эта ссылка → 1920 × 1080.

Важно: эта тестовая сборка сама не запускает автоматические донаты, даже если в Firebase ранее было enabled=true.
