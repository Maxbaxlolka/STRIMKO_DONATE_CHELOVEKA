ВАЖНО: ПРАВИЛА FIREBASE REALTIME DATABASE

Код панели исправлен, но Firebase всё равно не позволит сохранять настройки,
если в Realtime Database запрещена запись пути donateManager.

Открой:
Firebase Console → Realtime Database → Rules

В существующие rules добавь раздел donateManager.
Не удаляй свои правила для messages и других разделов.

Пример структуры:

{
  "rules": {
    "messages": {
      ...ЗДЕСЬ ОСТАВЬ СВОИ ТЕКУЩИЕ ПРАВИЛА...
    },

    "donateManager": {
      ".read": true,
      ".write": true
    }
  }
}

После изменения нажми Publish / Опубликовать.

ВНИМАНИЕ:
Публичная запись удобна для тестирования, но любой человек, знающий адрес базы,
теоретически сможет менять эти данные. Для постоянного использования лучше
добавить Firebase Authentication и разрешить запись только владельцу.
